# 🎨 Android Dark Neon Glassmorphic UI/UX Skill

## 1. Core Visual Tokens
- **Background Palette:**
  - Deep Space Canvas: `#05080F`
  - Elevated Glass Card: `#0D1522` with `#1E293B` 1dp border
  - Secondary Card Layer: `#142233`
- **Neon Accent Colors:**
  - JARVIS Core Cyan: `#00E5FF` (Glow: `#3300E5FF`)
  - NAIRA Companion Rose Gold: `#FF4081` (Glow: `#33FF4081`)
  - Live Status Green: `#10B981`
  - Warning Amber: `#F59E0B`
  - Circuit Breaker Red: `#EF4444`
- **Typography Tokens (Bundled):**
  - Futuristic Display / Headers: `@font/orbitron_bold`
  - Body & High-density Telemetry: `@font/rajdhani_semibold` and `@font/rajdhani_regular`

## 2. Component Guidelines
- **Cards & Surfaces:** Rounded corners (16dp-20dp), subtle glass borders (`@drawable/bg_jarvis_card`), high contrast readability.
- **Micro-interactions:** Ripples with `#3300E5FF`, smooth state transitions (inactive dim `#7FA3B5` vs active neon `#00E5FF`).
- **Telemetry Indicators:** Glowing pulse rings for active agents, clean status badges (`PASS ✅` / `FAIL ❌`).
